# Inkerio Content Template

[简体中文](README_ZH.md)

Content template for [Inkerio](https://github.com/ThinkerQAQ/inkerio), including sample content, site configuration and a GitHub Pages workflow.

Select **Use this template → Create a new repository** to create your blog.

Follow the [Inkerio Quick Start](https://github.com/ThinkerQAQ/inkerio/blob/main/README.md#2-quick-start) for setup and deployment. Local preview, usage and troubleshooting are maintained in the same README.
