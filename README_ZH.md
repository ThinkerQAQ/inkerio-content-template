# Inkerio Content Template

[English](README.md)

[Inkerio](https://github.com/ThinkerQAQ/inkerio) 的内容模板，包含示例内容、网站配置和 GitHub Pages 工作流。

点击 **Use this template → Create a new repository**，创建自己的博客仓库。

配置与部署见 [Inkerio Quick Start](https://github.com/ThinkerQAQ/inkerio/blob/main/README_ZH.md#2-quick-start)。本地预览、使用说明和常见问题统一在同一份 README 中维护。
