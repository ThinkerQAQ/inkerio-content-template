# Inkerio Content Template docs

[简体中文](zh-CN/index.md) · [Project README](../README.md) · [Inkerio engine](https://github.com/ThinkerQAQ/inkerio)

This repository provides **sample writing, content configuration, and synthetic media**.
There is no independent renderer, backend service or installer in this template.
Use the engine for preview and deployment; SyndiRelay is optional and separate.

`src/content/site/copyright.json` is an **example author-owned bilingual
policy**. The original template scaffolding is MIT; demo writing and media
are **not** automatically MIT. Replace the placeholder author, articles,
photos and sample license before operating your own public site.
